# Global-Airbnb-Performance-Dashboard
An interactive Power BI dashboard designed to explore Airbnb's global
listing performance, city-level market share, customer ratings, review
behaviour, seasonality, and host trust signals.
# Project Overview
This project brings Airbnb marketplace data together in a three-page
dashboard. It is intended to help users explore how listings vary across
cities and property types, how guests rate their stays, and what review
and host-verification patterns look like.

# Dashboard Pages
1. Overview
The Overview page provides a high-level snapshot of the marketplace,
including: - Total listings - Number of cities - Number of hosts -
Number of property types - Total reviews - New-listing trends over time,
split by property type

The trend chart also highlights marketplace phases such as introduction,
growth, maturity, decline, reinvention, and the COVID-19 period.
2. Ratings
The Ratings page focuses on city-level performance: - Market share by
city - Superhost and non-Superhost listing distribution - Cumulative
share across cities - Average price by property type - City-level rating
comparisons for accuracy, cleanliness, communication, location, and
value
3. Reviews
The Reviews page explores guest review patterns: - Distribution of
reviews per reviewer - Monthly review seasonality across selected
cities - Host trust and profile-verification indicators

# Key Observations Highlighted in the Dashboard
- The Overview page shows a strong rise in new listings through the
  marketplace's growth and maturity phases, followed by a decline
  around the COVID-19 period.
- The Ratings page highlights Paris, New York, and Sydney as major
  contributors to listings and reviews in the displayed city
  comparison.
- The dashboard compares average prices across property types, with
  hotel rooms shown at the highest average price in the displayed
  comparison.
- The Reviews page shows that most reviewers have left only a small
  number of reviews, while a small number of reviewers have much
  higher review counts.
- The seasonality visual suggests that review activity varies across
  months and cities.
- The trust visual compares profile-photo and verification signals for
  hosts.
These observations describe what is displayed in the dashboard. They
should be interpreted in the context of the dataset, filters, and date
range used in the report.
